# CYRA Biomedical Knowledge Base

CYRA is a structured biomedical engineering knowledge platform designed to transform medical equipment service intelligence into validated, searchable, AI-ready operational knowledge.

## Purpose

This repository stores:

* Complaint taxonomies
* Diagnostic workflows
* Service procedures
* Safety escalations
* FRU mappings
* Expert-reviewed biomedical knowledge

The goal is to build a validated biomedical service intelligence engine for healthcare equipment maintenance and troubleshooting.
